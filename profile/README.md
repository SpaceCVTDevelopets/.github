# 🚀 Boas-vindas à Organização SPACE-CVT! ✨

Que bom ter você por aqui! Esta é a organização oficial de desenvolvimento do **SPACE-CVT**, uma plataforma imersiva em Realidade Virtual voltada para o ensino de Astronomia e Astronáutica, concebida no âmbito do projeto **CVT-Espacial** no **Instituto Federal do Rio Grande do Norte (IFRN - Campus Parnamirim)**.

Nossa missão é transformar a aprendizagem espacial em uma vivência prática, divertida e inesquecível para o público infantojuvenil!

## 🌌 Sobre o Projeto

O **SPACE-CVT** une a abordagem pedagógica **STEAM** (_Science, Technology, Engineering, Arts and Mathematics_) e mecânicas de **gamificação** em ambientes imersivos de RV para permite que os estudantes interajam com simulações reais do setor aeroespacial e astronomia.

Como um projeto tecnológico e científico de evolução contínua, novos módulos, otimizações de código e refinamentos visuais são incorporados constantemente pelas equipes de bolsistas e pesquisadores.

## 🛠️ Nosso Ecossistema Tecnológico

-   **Game Engine & Código:** Unity 6 (C#)
    
-   **Modelagem 3D & Arte:** Blender (Design _Low Poly_)
    
-   **UX / UI Design:** Figma & Meta Horizon OS UI Set
    
-   **Plataforma VR / Hardware:** Meta Quest 3 (OpenXR / Meta XR SDK)
